# DevRise Admin Dashboard — Implementation Specification

## Project Context

I have an existing tutorial website called **DevRise**.

The existing public website is already designed and functional. **Do not redesign, restructure, or replace the existing public-facing website.**

The goal of this task is to add a **separate, secure Admin Dashboard** that allows me to manage the tutorial platform.

The backend is built with **Python/Flask**.

The Admin Dashboard should work alongside the existing website without breaking any existing functionality.

---

# 1. Admin-Only Access

Create a secure admin authentication/authorization system.

Only users with an `admin` role should be able to access the Admin Dashboard.

Example user roles:

```text
student
admin
```

A student must not be able to access admin pages or admin API endpoints by manually entering the admin URL.

Protect both:

* Frontend admin routes
* Flask backend admin API endpoints

If an unauthenticated user tries to access the dashboard, redirect them to login.

If an authenticated non-admin user tries to access it, return/display an appropriate unauthorized/forbidden response.

Do not rely only on hiding the admin link. The Flask backend must enforce authorization.
